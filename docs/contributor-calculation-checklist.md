# Contributor calculation checklist

For any calculation change, document:

- input field and accepted unit;
- physical or monetary denominator;
- formula before rounding;
- rounding point and method;
- payer and cash-timing effect;
- seller, buyer and unit-economics outputs affected;
- positive example;
- zero or boundary example;
- invalid-input example;
- Golden fixture impact;
- compatibility or schema-version decision;
- interpretation boundary.

A pull request that changes a number without explaining this chain is incomplete.
