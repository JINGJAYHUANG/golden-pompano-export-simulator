# Maturity model

| Level | Evidence required | Permitted claim |
|---|---|---|
| L0 — Formula draft | Unreviewed equations or spreadsheet logic | Concept only |
| L1 — Unit validated | Positive and boundary tests for each calculation | Calculation module behaves as specified |
| L2 — Fixture validated | Deterministic synthetic end-to-end scenarios | Software workflow works on fixtures |
| L3 — Historical reconciled | Sanitized real shipment or quote reconciled against records | Model reproduced that historical case within stated tolerance |
| L4 — Operationally controlled | Current evidence owners, approvals and repeated private use | Model supports a controlled operating process |
| L5 — Independently assured | External accounting, customs, legal and operational review as applicable | Narrow assurance within reviewed scope |

v0.1.0 is released at **L2 — fixture validated** with integrity controls. It does not claim historical reconciliation or operational assurance.
