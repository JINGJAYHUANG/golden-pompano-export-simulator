# Model governance principles

1. **Explicit denominator.** No unlabeled per-kilogram price or cost.
2. **Two-sided economics.** Seller profit and buyer landed cost are separate views.
3. **Cash is not profit.** Timing and working-capital need remain visible.
4. **Recoverability is an assumption.** Tax credits are never inferred.
5. **Contract beats template.** Illustrative cost allocation must be replaced by the signed arrangement.
6. **Negative results remain visible.** The model is not optimized to produce an attractive margin.
7. **Assumptions expire.** Current evidence must be revalidated for each quote.
8. **Source and calculation are separable.** A valid run can still begin with a wrong input.
9. **Integrity is testable.** Inputs, outputs and event order are content-addressed.
10. **Humans authorize commitments.** The software does not send quotes, accept terms or move money.
