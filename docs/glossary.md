# Glossary

| Term | Meaning in this project |
|---|---|
| Net fish mass | Fish mass excluding ice glaze and packaging |
| Glazed product mass | Net fish plus ice glaze, excluding packaging |
| Packaged gross mass | Glazed product plus carton, liner and pallet tare |
| Price basis | Physical denominator attached to a unit price |
| Landed cash cost | Cash paid for invoice, buyer costs and taxes |
| Landed economic cost | Landed cash cost less assumed recoverable tax and credits |
| Working-capital need | Peak cumulative seller cash deficit before later receipts |
| Break-even price | Quote unit price producing zero modelled seller profit after share |
| Target-margin price | Quote unit price satisfying a declared seller margin |
| Cost-responsibility profile | Editable stage-to-payer calculation map |
| Incoterm label | Contract metadata; not a complete legal interpretation in this software |
| Golden fixture | Committed synthetic scenario and expected deterministic output |
| Semantic SQLite digest | Hash of ordered table schema and content rather than file-page bytes |
| Run manifest | Identity record linking scenario, outputs and final event hash |
