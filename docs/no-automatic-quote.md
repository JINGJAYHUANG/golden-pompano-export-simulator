# No automatic quotation or commitment

The package can calculate and report a scenario. It cannot:

- send a quotation;
- accept a buyer price;
- confirm product availability;
- commit a shipment date;
- approve a discount;
- sign a contract;
- instruct a bank or payment provider;
- file customs documents;
- book transport.

Those actions require explicit human authorization and the appropriate external systems. A generated report is an analytical artifact, not a commercial offer.
