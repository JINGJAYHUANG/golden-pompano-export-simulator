# Scenario naming policy

Use stable, non-personal identifiers that communicate purpose without exposing counterparties:

```text
SYN-CIF-BASELINE
SYN-CIF-RESILIENT
PRIVATE-ROUTE-A-2026Q3-BASE
PRIVATE-ROUTE-A-2026Q3-FX-STRESS
```

Do not place buyer names, supplier names, phone numbers, ports tied to confidential negotiations or contract numbers in a public scenario ID.

A revised assumption set should receive a new scenario version or identity. Do not overwrite an old run and preserve its manifest as though the assumptions had never changed.
