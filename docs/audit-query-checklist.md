# Audit query checklist

A reviewer should be able to answer from the output bundle:

1. Which scenario and source date produced this result?
2. What physical mass does the quoted unit price divide by?
3. How many integer cartons, pallets and containers are assumed?
4. Who pays each cost line after contract overrides?
5. What is the customs-value assumption?
6. Which taxes are cash outflows and which are assumed recoverable?
7. What is the seller's peak cash deficit and financing cost?
8. How is profit share calculated?
9. What is the buyer's cash landed cost and economic landed cost?
10. Which input changes reverse profitability or target margin?
11. Do all generated files match the artifact manifest and event chain?
12. Which legal, customs, tax, quality and payment questions remain outside the model?

If these questions cannot be answered, the run is not ready for decision use even when the headline profit appears attractive.
