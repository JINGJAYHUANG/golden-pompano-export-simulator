# Unit conversion examples

Assume:

```text
net fish = 18,000 kg
glaze = 10% of glazed-product mass
carton declared product = 20 kg
carton tare = 1.10 kg
1,000 cartons and 20 pallets
pallet tare = 25 kg
```

Then:

```text
glazed product = 18,000 / 0.90 = 20,000 kg
ice = 20,000 - 18,000 = 2,000 kg
carton tare = 1,000 × 1.10 = 1,100 kg
pallet tare = 20 × 25 = 500 kg
packaged gross = 20,000 + 1,100 + 500 = 21,600 kg
```

A shipment invoice of USD 111,000 therefore equals:

```text
USD 6.1667 per net-fish kg
USD 5.5500 per glazed-product kg
USD 5.1389 per packaged-gross kg
USD 111.00 per carton
```

These arithmetic examples use the synthetic fixture only and are not current commercial values.
